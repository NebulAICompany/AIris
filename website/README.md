# AIris Product Website

A professional website for AIris - AI-Powered Financial Document Processing by Nebula Intelligence.

## Overview

This website showcases AIris, an advanced desktop application that revolutionizes financial document processing through cutting-edge AI technology. The site features a stunning **Nebula theme** inspired by the original AIris application design, creating an immersive cosmic experience.

## Features

### Design & Aesthetics

- **Nebula Theme**: Cosmic background with animated nebula effects and star fields
- **Responsive Design**: Optimized for all devices and screen sizes
- **Modern UI**: Clean, professional interface with glassmorphism effects
- **Smooth Animations**: Engaging scroll-triggered animations and interactions
- **Dark Theme**: Space-inspired color palette with purple/pink gradients

### Content Sections

1. **Hero Section**: Compelling introduction with animated statistics
2. **Features**: Comprehensive overview of AIris capabilities
3. **Technology**: Technical stack and AI capabilities showcase
4. **Demo**: Video demonstration and screenshot gallery
5. **About**: Nebula Intelligence company information
6. **Contact & Download**: Multiple platform download options

### Technical Features

- **SEO Optimized**: Meta tags, Open Graph, and semantic HTML
- **Performance Focused**: Optimized animations and efficient code
- **Accessibility**: ARIA labels and keyboard navigation support
- **Progressive Enhancement**: Works without JavaScript, enhanced with it

## Installation & Setup

1. **Clone or download** the website files
2. **Add required assets** to the `assets/` directory:

   - `logo.png` - AIris logo
   - `favicon.ico` - Website favicon
   - `og-image.jpg` - Social media preview image
   - Screenshot images for the gallery

3. **Customize content** as needed:

   - Update contact information
   - Modify company details
   - Add actual download links
   - Replace placeholder content

4. **Deploy** to your web server or hosting platform
