# AIris App Icon

This directory should contain the application icons:

- `icon.png` - Main application icon (256x256 or higher)
- `icon.ico` - Windows icon file
- `icon.icns` - macOS icon file

For now, the application will use the default Electron icon.

To add custom icons:

1. Create or obtain application icons in the required formats
2. Place them in this directory
3. Update the build configuration in package.json if needed
